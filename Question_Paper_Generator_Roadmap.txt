QUESTION PAPER GENERATOR — APPLICATION ROADMAP
=================================================

PROJECT GOAL
------------
Build an application that imports an Excel question bank and automatically generates
professionally formatted question papers in PDF and Word (.docx).

The question bank should store, at minimum:
- Subject
- Module / Chapter
- Question
- Question Type
- Marks
- Difficulty
- Options (for MCQs)
- Correct Answer / Answer Key (optional, kept separate from student paper)
- Explanation / Marking Scheme (optional)
- Source / Year (optional)
- Question ID

The generator should allow a teacher to:
1. Upload an Excel question bank.
2. Select a subject.
3. Select one or more chapters/modules.
4. Set the target maximum marks for the paper.
5. Define how many questions of each type are required.
6. Optionally define chapter-wise mark distribution.
7. Automatically select questions without exceeding the target.
8. Avoid duplicate questions.
9. Shuffle questions and/or options.
10. Preview and manually replace individual questions.
11. Export the final paper to Word and PDF.
12. Optionally export a separate answer key / marking scheme.

IMPORTANT CBSE DESIGN NOTE
--------------------------
For a real CBSE-style implementation, do not treat "total marks" as the only constraint.
The generator should support a paper blueprint.

For example:
- Total marks: 80
- 1-mark questions: specified count
- 2-mark questions: specified count
- 3-mark questions: specified count
- 4-mark case-study questions: specified count
- 5-mark questions: specified count
- Chapter/module coverage
- Question-type coverage
- Difficulty distribution

The official CBSE Class X 2025-26 Mathematics Standard sample paper, for example,
uses 20 one-mark questions, 5 two-mark questions, 6 three-mark questions,
4 five-mark questions and 3 four-mark case-study questions. Science and English
use different structures, so the application should store subject-specific blueprints
rather than hard-code one format.

PHASE 4 — QUESTION SELECTION ENGINE
------------------------------------
This is the core of the application.

Inputs:
- Target total marks
- Selected subject
- Selected chapters
- Required question types
- Required number of questions
- Optional chapter mark distribution
- Optional difficulty distribution
- Optional exclusions
- Randomization seed

Basic algorithm:
1. Filter by subject.
2. Filter by selected chapters.
3. Filter by active questions.
4. Filter by question type.
5. Group questions by marks/type/chapter.
6. Find a combination whose total marks exactly matches the target.
7. Check blueprint constraints.
8. Check chapter coverage.
9. Check difficulty distribution.
10. Randomly select among valid combinations.
11. Return the selected questions.
12. If no valid paper exists, explain exactly which constraint cannot be satisfied.

Do NOT use a simple random loop as the final algorithm.

Better approaches:
- Dynamic programming for exact mark totals.
- Constraint satisfaction / optimization for multiple constraints.
- Integer Linear Programming later if the blueprint becomes complex.

Example:
Target = 40 marks

The engine might find:
10 x 1 mark = 10
5 x 2 marks = 10
4 x 3 marks = 12
2 x 4 marks = 8
Total = 40

The actual blueprint can be different for each subject.

PHASE 14 — DUPLICATE DETECTION
------------------------------
Implement duplicate detection using:
1. Exact text matching.
2. Normalized text matching.
3. Later: semantic similarity using embeddings.

Do not automatically delete possible duplicates.
Flag them for teacher review.

------------------------

Store the seed with generated papers so a paper can be reproduced later.

PHASE 18 — SECURITY AND PRIVACY
-------------------------------
Never upload or commit:
- Real student information
- Teacher passwords
- API keys
- Database credentials
- Private question banks
- Generated answer keys containing sensitive information

Use:
.env
.gitignore

If the application is deployed online:
- Validate uploaded files.
- Limit file size.
- Restrict file extensions.
- Sanitize filenames.
- Do not execute uploaded files.
- Store uploaded files outside public directories.
- Add authentication before allowing private question banks.

IMPORTANT DATASET NOTE
----------------------
The accompanying Excel file is a starter question-bank dataset based on CBSE Class X
2025-26 curriculum/sample-paper structures. It is intended for software development
and testing, not as an official CBSE question bank.

CBSE's official 2025-26 Class X material provides sample question papers and marking
schemes for Mathematics, Science and English Language & Literature. The official
Science paper is an integrated Science paper whose Physics questions form only one
section; therefore, the dataset treats Physics as a development-friendly subject
category rather than claiming that CBSE Class X has a separate Physics board paper.

For production use, verify the current CBSE syllabus, assessment scheme, sample papers,
and official marking schemes before creating an exam paper.

FIRST VERSION TARGET
--------------------
Build the selection engine first.

If the algorithm cannot reliably produce:
- exact total marks,
- selected chapter coverage,
- requested question types,
- no duplicates,
- and a clear error when a paper is impossible,

do not move on to PDF formatting.

The selection engine is the most important technical component of this application.
